# Theming

Fibbers cards **follow your Home Assistant theme automatically**: light on a light HA theme,
dark on a dark one. There's nothing to configure and nothing to install — each card reads
`hass.themes.darkMode` (the same signal the rest of Home Assistant uses) and switches its
palette to match. In this Storybook, use the **Theme** switch in the toolbar to preview both.

The `theme:` option on the **nav** card is separate and optional: it re-tints Home Assistant's
own chrome — the header, sidebar, more-info dialogs and native switches/sliders — to match the
Fibbers palette, which HA doesn't do for a Lovelace plugin on its own. It sets HA's theme custom
properties (scoped to the dashboard, or on `html` for the `-global` modes). **No separate theme
repository, no `card-mod`.**

## The palette

Green is the brand/active colour; amber is kept for warnings only.

| Token             | Value     | Role                                                     |
| ----------------- | --------- | -------------------------------------------------------- |
| `--fib-bg`        | `#111516` | page ground                                              |
| `--fib-card`      | `#1D2426` | card surface                                             |
| `--fib-sheet`     | `#171E20` | modal sheet surface                                      |
| `--fib-line`      | `#333E41` | borders                                                  |
| `--fib-ink`       | `#EDF1F1` | primary text                                             |
| `--fib-muted`     | `#7D8B8E` | labels / inactive                                        |
| `--fib-accent`    | `#74B98A` | **brand accent — soft forest green** (active / lit / on) |
| `--fib-accent-bg` | `#17281C` | green tint (icon-on box)                                 |
| `--fib-amber`     | `#E8A33D` | **warning only** (the alert card)                        |
| `--fib-green`     | `#63C295` | success                                                  |
| `--fib-red`       | `#EC8377` | error / offline                                          |
| `--fib-blue`      | `#5AAFD6` | info / active-secondary                                  |

Semantics: **green** = brand / active / positive, **amber** = attention, **red** = error,
**blue** = info. Lit rooms and active scenes glow
`linear-gradient(145deg, #1E3427, #132016)` with a `#2E5238` border.

### Light mode

On a light HA theme the same roles resolve to a legible light palette — near-white surfaces
(`#FFFFFF` cards on an `#EEF1F0` ground), dark ink (`#14201A`), a deeper green accent
(`#2F6B45`) that reads on white, and darkened amber/red/blue so status colours stay legible.
The lit-tile glow becomes a soft green wash (`linear-gradient(145deg, #E7F4EC, #DDEEE3)`).
The switch is automatic — it tracks `hass.themes.darkMode`, so you never set it by hand.

## A user-selectable theme instead

The injector is the default, but a standalone theme file is available if you'd rather select one
in your profile: copy
[`docs/optional-theme.yaml`](https://github.com/Elian0213/fibbers-home-assistant/blob/main/docs/optional-theme.yaml)
to `/config/themes/fibbers.yaml` and pick it under **Profile → Theme**. It sets the same values.

## Turning the injector off

Set this before the plugin loads (for example if you already run a theme you like):

```js
window.FIBBERS_DISABLE_GLOBAL_CSS = true;
```
