# Installation

Fibbers is a HACS **Dashboard** plugin — one JavaScript resource, no integration, no restart.

## Via HACS (recommended)

1. **HACS → ⋮ → Custom repositories.** Add the repository URL
   `https://github.com/Elian0213/fibbers-home-assistant` with category **Dashboard**.
2. Find **Fibbers** in HACS and **Download**.
3. HACS usually registers the Lovelace resource for you. If not, add it manually under
   **Settings → Dashboards → ⋮ → Resources → Add**:

   ```text
   URL:  /hacsfiles/fibbers-home-assistant/fibbers.js
   Type: JavaScript module
   ```

4. **Hard-reload** the browser (Ctrl / Cmd + Shift + R).

The cards load with automatic light/dark theming — there's nothing else to install (no `card-mod`,
no `kiosk-mode`, no separate theme repository).

> **Tip.** In this Storybook, every card story has a **Show code** button (and a **Docs** tab)
> that shows the exact Lovelace YAML — copy it straight into a card on your dashboard.

## Requirements

- Home Assistant **2025.1** or newer (verified on 2026.8.x).
- Any modern browser; the bottom bar is tuned for the iOS companion app.

## Theming

Loading the plugin leaves the rest of Home Assistant untouched; cards follow your HA light/dark
theme on their own. See [Theming](?path=/docs/getting-started-theming--docs) for the optional
`theme:` on the nav card and the installable HA theme, and
[Usage](?path=/docs/getting-started-usage--docs) for a full dashboard example.
