# Fibbers

A phone-first, bottom-nav dashboard for Home Assistant: a **viewport-pinned bottom bar**, a
back-stack, drag-away **modal sheets**, self-computing **room tiles**, an **alert card** built
from real checks, and automatic **light/dark theming**.

Built with Lit. This Storybook renders the real shipped bundle (`dist/fibbers.js`) against a
stubbed Home Assistant, so every card in the sidebar is live. Open a card's **Docs** tab, or hit
**Show code**, to copy its exact **Lovelace YAML**.

## Install

Fibbers is a HACS **Dashboard** plugin (a Lovelace resource):

```text
HACS → ⋮ → Custom repositories → add
  Elian0213/fibbers-home-assistant   (category: Dashboard)
→ Download → hard-reload the browser
```

Full steps, including the resource path, are on the
[Installation](?path=/docs/getting-started-installation--docs) page.

## Use it

One card is a few lines of YAML. A room tile that reads its own lights:

```yaml
type: custom:fibbers-room
name: Woonkamer
icon: solar:sofa-2-bold-duotone
sheet: woonkamer
entities:
  - light.tv_led_strip
  - light.kitchen
  - light.woonkamer_computer
```

See [Usage](?path=/docs/getting-started-usage--docs) for a full copy-paste "Huis" view built
only from Fibbers cards, and [Theming](?path=/docs/getting-started-theming--docs) for the
palette and the global CSS injector.

## What's inside

28 cards, grouped in the sidebar by role:

- **Shell & Navigation** — nav, back, section, sheet, greeting
- **Rooms, Lights & Scenes** — room, light-group, light-row, light-detail, scene, chips
- **Status & Data** — alert, stat, graph, entities, presence, backup, weather, sysmon
- **Devices & Media** — media, remote, climate
- **Inputs & Controls** — number, select, toggle, datetime, scheduler, alarm

Each card has its own sidebar section with live examples and copy-paste YAML.

Every card **follows your Home Assistant theme** — light on a light HA theme, dark on a
dark one, automatically. Use the **Theme** switch in the toolbar above to preview both.
